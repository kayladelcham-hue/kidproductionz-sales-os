# Bundled fonts

Manrope is sourced from the Google Fonts repository: https://github.com/google/fonts/tree/main/ofl/manrope . The complete variable TTF was losslessly compressed to WOFF2 using fontTools, retaining the original glyphs and 200–800 weight axis. No outlines were modified or subsetted. Its SIL Open Font License is included in OFL-Manrope.txt.

Upstream TTF SHA-256: 3ae11c49db0455a3cc33e37d380f20fdb8c7f8b41dc07625c177e3d87a9d6ae6

The app uses weights 400 (body/labels), 500 (controls/navigation), and 600 (business names/emphasis). Manrope loads from the same origin with font-display: swap. The existing Bebas Neue asset remains for major KP page headings, with its existing license.
